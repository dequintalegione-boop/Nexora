# Nexora

Персональная система управления жизнью, задачами и временем (PWA).

Полнофункциональное локальное приложение: задачи, привычки, проекты, направления, цели, ежедневник, таймер и дашборд с настраиваемыми виджетами. Данные хранятся локально (Zustand + persist).

## Онлайн

После деплоя: **https://dequintalegione-boop.github.io/Nexora/** (или Vercel)

## Локальный запуск

```bash
git clone https://github.com/dequintalegione-boop/Nexora.git
cd Nexora
npm install
npm run dev
```

Открой http://localhost:8080 (или порт из вывода).

## Что есть

- **Dashboard** — прогресс дня, привычки, задачи, «Чем заняться?», виджеты (перестановка, скрытие)
- **Задачи** — статусы, приоритеты, проекты, направления, подзадачи, повторы, оценка времени
- **Привычки** — конструктор, логи, пропуски с причиной
- **Проекты и направления**
- **Цели** с горизонтами
- **Ежедневник** — настроение, энергия, рефлексия
- **Таймер** (free / focus / break)
- Тёмная/светлая/системная тема + акцентный цвет
- Экспорт/импорт бэкапа

## Стек

- Vite + TanStack Start / React Router
- TypeScript
- Tailwind CSS v4 + Radix UI
- Zustand (persist)
- date-fns
- PGlite (опционально, сейчас выключен)
- better-auth (выключен)
