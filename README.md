## Запуск

```bash
git clone https://github.com/dequintalegione-boop/Nexora.git
cd Nexora
npm install
npm run dev
```

Открой http://localhost:8080 (или порт из терминала).

Раздел **Обзор** (`/analytics`) — Weekly Review.

## Стек

Vite · TanStack Router · React 19 · TypeScript · Zustand · Tailwind CSS v4 · date-fns
