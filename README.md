# Nexora

Персональная система управления жизнью, задачами, привычками, целями и временем (PWA).

## Статус реализации (по PRODUCT_SPECIFICATION)

| Раздел ТЗ | Статус | Комментарий |
|-----------|--------|-------------|
| 3. Dashboard + виджеты | ✅ | Прогресс дня, «Чем заняться?», задачи, привычки, проекты, быстрый захват, неделя. Можно менять порядок и скрывать виджеты |
| 3. Главный результат дня | ✅ | Поле focus в прогрессе дня |
| 5. Ежедневник | ✅ | Настроение, энергия, рефлексия (wins/best/challenges), завтрашний фокус, контекст задач/привычек |
| 6. Привычки | ✅ | Типы измерения, пропуски, **серии (streak)**, рекорд, регулярность % |
| 7. Задачи | ✅ | Статусы, приоритеты, **список + канбан**, фильтры, история изменений |
| 8. Проекты / Направления | ✅ | Есть |
| 9. Цели | ✅ | Горизонты, статус, прогресс |
| 10. «Чем заняться?» | ✅ | Алгоритм на приоритете + сроке + энергии + доступном времени |
| 11. Календарь | 🟡 | Базовая недельная сетка |
| 12. Аналитика / Weekly Review | 🔴 | Пока нет отдельной страницы |
| Темы + акцент | ✅ | Светлая / тёмная / системная + выбор акцента |
| Экспорт / бэкап | ✅ | В настройках |

## Запуск

```bash
git clone https://github.com/dequintalegione-boop/Nexora.git
cd Nexora
npm install
npm run dev
```

## Стек

- Vite + TanStack Router / Start
- React 19 + TypeScript
- Zustand (persist)
- Tailwind CSS v4 + Radix
- date-fns
