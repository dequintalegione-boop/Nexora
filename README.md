# Nexora

**Nexora** — персональная система управления жизнью, задачами, знаниями и временем в формате Progressive Web App (PWA).

Это не плагин Obsidian и не оболочка над Obsidian. Nexora развивается как отдельный продукт.

## Текущий статус

**Этап 1 — Основа** (в работе)

Реализовано:
- Каркас Vite + React 19 + TypeScript
- Tailwind CSS v4 + тёмная тема
- React Router с базовой навигацией
- Dexie.js (IndexedDB) — схема данных для задач, проектов, направлений, привычек, ежедневника, целей, сессий времени
- Zustand для UI-состояния
- PWA-манифест и service worker (vite-plugin-pwa)
- Адаптивный layout с боковой панелью
- Dashboard с живыми счётчиками из БД

## Принципы

1. **Единая система** — задачи связаны с проектами, проекты с направлениями, цели с проектами.
2. **Настраиваемость** — пользователь управляет виджетами, статусами, привычками, темами.
3. **Прозрачность данных** — экспорт, импорт, резервное копирование.
4. **Самостоятельность** — основные функции внутри Nexora.
5. **Постепенное развитие** — модули выпускаются поэтапно.

## Важное ограничение первой версии

AI-функции предварительно исключены. Рекомендации и аналитика работают на правилах и фактических данных.
